# BrokerCRM

CRM para equipos de corretaje en Chile. Centraliza la gestión de leads desde la captación hasta el cierre.

- **Leads:** asignación y reasignación automática.
- **Equipos:** roles y estructura para organizar la gestión comercial.
- **Métricas:** seguimiento de resultados por equipo.
- **Agenda:** integración con Google Calendar.

[Conoce BrokerCRM](https://www.brokercrm.cl)
